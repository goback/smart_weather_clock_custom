# 장치 상태 기록

기록일: 2026-11-08 (Asia/Seoul).

출처: 기존 채팅 [SmallTV-Ultra 기능 확인](codex://threads/01a1b94e-b2fc-7b00-bf4f-aca7c09980a5)의 전체 대화 및 빌드·검증 출력. 아래 실기 결과는 **그 채팅에서 확인한 시점의 기록**이며, 이번 문서화 작업에서 장치에 다시 접속한 결과는 아닙니다.

## 장치와 펌웨어

| 항목 | 확인 내용 |
| --- | --- |
| 판매명 | GeekMagic SmallTV-Ultra |
| 호환 계열 | 원래 관리 페이지에 SD PRO용 펌웨어 안내가 있었고, SD PRO용 커스텀 빌드의 부팅·화면 출력을 사용자가 확인함 |
| 화면 | 240×240 |
| 빌드 대상 | ESP8266 / `esp12e`, CPU 80 MHz, RAM 80 KiB, 플래시 4 MB 구성 |
| 기반 소스 | SmartClock-OSS v1.3.2 |
| 마지막 적용 파일 | `SDP-Minimal-Clean64.bin` |
| 소스의 버전 문자열 | `1.3.2-minimal-clean64` |
| 마지막 관리 주소 | 로컬 네트워크에서 `http://192.168.0.57/` 사용. DHCP 배정에 따라 달라질 수 있음 |

정확한 기판 모델·리비전은 분해해서 확인하지 않았습니다. 최초 제조사 펌웨어의 설치 버전도 확인하지 못했습니다. 빌드 대상과 실기 동작 확인을 기판 각인 확인으로 해석하지 않습니다.

외부 USB 연결에서는 장치의 데이터용 직렬 포트를 확인하지 못했습니다. 분해 없는 전체 플래시 백업도 확보하지 않았습니다.

## 남긴 기능과 제거한 기능

남긴 기능:

- `BOOT OK`와 1초마다 갱신되는 부팅 후 경과 시간.
- Wi-Fi 검색·연결, 장치 IP 표시, 설정용 AP.
- 밝기 1~100%: 슬라이더 조정 중 즉시 적용하고 조정 종료 후 약 0.5초에 마지막 값 자동 저장.
- 관리 페이지 로그인·로그아웃, 장치 화면에서 비밀번호 확인, 현재 비밀번호를 확인한 뒤 새 비밀번호로 변경.
- 읽기 전용 파일 목록: 전체 경로·크기, 크기 내림차순과 합계.
- 파일 저장 영역의 전체·남은 용량 표시.
- 웹 펌웨어 업데이트와 부팅 실패 복구 모드.
- 지정된 구형 파일 64개를 한 번 정리하는 기능과 정리 상태 표시.

제거한 기능:

- 날씨 조회·예보, 사진 앨범·업로드·GIF 재생.
- 기존 테마, 인터넷 시각 동기화, 야간 모드.
- Home Assistant·MQTT 연동, RGB 테스트 막대.

밝기 설명 문구와 별도 밝기 저장 버튼은 제거했습니다. SSH·브라우저 콘솔은 구현하지 않았습니다. 앞부분에서 조사한 제조사 `/theme/*`, `/photo/*` API를 현재 최소 펌웨어가 제공한다고 가정하면 안 됩니다.

## 유지해야 할 데이터

| 저장 위치 | 의미와 처리 |
| --- | --- |
| `/sdpro-minimal.json` | Wi-Fi 연결 정보와 밝기 설정. 마지막 파일 목록에서 68바이트로 존재 확인. 내용에 비밀번호가 포함될 수 있으므로 실제 파일은 저장소에 넣지 않음 |
| EEPROM 영역 | 장치 로그인 비밀번호. LittleFS 설정 파일과 별도이며 기존 값을 유지함 |
| `/.sdpro-clean64.done` | 0바이트 정리 완료 표시. 현재 펌웨어에서는 유지 |

장치 로그인 비밀번호는 설정용 Wi-Fi의 비밀번호로도 사용합니다. 변경 기능은 새 비밀번호를 두 용도에 적용합니다.

완료 표시가 있으면 현재 펌웨어는 다음 부팅에서 정리를 건너뜁니다. 표시를 지우면 다음 부팅에 동일한 64개 경로를 다시 검사하고 표시를 다시 만들 수 있습니다. 자동 정리 기능을 제거한 후속 펌웨어에서는 이 표시도 필요 없어집니다.

## 마지막 실기 정리 결과

사용자가 Clean64 빌드를 적용한 뒤, 기존 채팅에서 `/status`와 로그인 후 파일 목록을 조회했습니다.

- 불필요한 파일 64개 삭제 확인.
- 남은 파일은 `/sdpro-minimal.json`(68바이트), `/.sdpro-clean64.done`(0바이트) 두 개.
- 삭제 대상 파일 내용 크기 합계: 1,183,573바이트.

| 파일 저장 영역 | 바이트 |
| --- | ---: |
| 전체 | 3,121,152 |
| 정리 전 여유 | 1,581,056 |
| 정리 후 여유 | 3,096,576 |
| 늘어난 여유 | 1,515,520 |

삭제 파일의 크기 합계와 확보 공간은 LittleFS의 블록 할당·관리 공간 때문에 다릅니다. 플래시 전체 4 MB와 파일 저장 영역 약 2.98 MiB도 서로 다른 값입니다.

[정리 대상 목록](evidence/legacy-assets.json)은 Clean64의 `src/legacy_assets.h`에 있던 경로·바이트 수를 옮긴 기록입니다. 기존 정리 코드는 설정을 정상적으로 읽은 뒤, 목록의 **경로와 크기가 모두 일치하는 일반 파일만** 삭제했습니다. 다른 경로·크기와 추가 파일은 삭제 대상이 아니었습니다. 이 목록 자체는 실행 코드가 아닙니다.

이전 단계의 `정리 완료`는 사진 앨범과 구형 설정 파일 일부만을 의미했습니다. 저장소 전체가 정리됐다는 판단에는 위의 최종 Clean64 결과를 사용합니다.
